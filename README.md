# Consensus Golfers

## Starting the system

Run all commands from the root of the repository.

Start each node in its own terminal:

**Terminal 1**
```bash
go run . -id 1
```

**Terminal 2**
```bash
go run . -id 2
```

**Terminal 3**
```bash
go run . -id 3
```

## Stopping the system

Press `Ctrl+C` in each terminal.
